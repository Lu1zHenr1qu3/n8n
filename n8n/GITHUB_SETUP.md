## Como Configurar no GitHub

1. **Acesse seu repositório:** https://github.com/Lu1zHenr1qu3/n8n
2. **Clique em "Settings"** (Configurações)
3. **Role até a seção "About"**
4. **Preencha:**
   - **Description:** Cole a descrição curta acima
   - **Topics:** Adicione os topics sugeridos (um por vez)
   - **Website:** (Opcional) Deixe em branco ou adicione seu portfólio
5. **Salve as alterações**
